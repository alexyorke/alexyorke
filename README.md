# Alex Yorke

Senior Staff Software Engineer at Palo Alto Networks, previously at Microsoft.

I build backend and platform software, mostly in C#, Python, and TypeScript. I'm interested in debugging complex systems, safer releases, and tools that make software easier to understand, test, and operate.

- Static analysis, symbolic verification, and developer tooling
- CI/CD, release engineering, and developer productivity
- Reliability, debugging, and operational improvements

## Selected projects

### [SharpProof](https://github.com/alexyorke/SharpProof)

A preview C# tool for checking contracts, purity, and side effects with Roslyn analysis and bounded, Z3-backed verification. Formerly PurelySharp.

### [Beginning CI/CD](https://github.com/alexyorke/beginning-ci-cd-book)

A work-in-progress guide to building and maintaining CI/CD pipelines with GitHub Actions. [Read online](https://alexyorke.github.io/beginning-ci-cd-book/).

### [branch-pad](https://github.com/alexyorke/branch-pad)

An interactive Python notebook environment for exploring multiple branches of code execution.

### [ssd-protect](https://github.com/alexyorke/ssd-protect)

A utility that alerts you when an application writes excessive amounts of data to your SSD.
